## Interpretation Notes

- `Bootstrap Strength` means “how directly this project helps standardize new project setup.”
- `V1 Fit` means “how directly this project can inform a lean internal starter without dragging in runtime scope.”
- `Reference Value` means “how valuable this project is as a long-term architectural benchmark even if it is too heavy for v1.”
- `Memory / Compounding` distinguishes between explicit durable substrate and lighter document or git-backed compounding habits.
- The labels are qualitative synthesis, not numeric measurements.

## Important Distinctions

- `compound-engineering-plugin` is stronger as a methodology and packaging benchmark than as a runtime benchmark.
- `gstack` is stronger as a rich control-plane and persistence benchmark than as a minimal starter template.
- `superpowers` is stronger as a lifecycle-discipline benchmark than as a runtime architecture benchmark.
- `oh-my-codex` is the clearest Codex-native benchmark in this pass for state authority and operational control.
- `Archon` is the clearest benchmark in this pass for deterministic workflow and config precedence.
- `OpenHarness` is the clearest benchmark in this pass for broader runtime substrate concepts such as profiles, permissions, and markdown-first memory.
